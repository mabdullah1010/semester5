# Project Explanation Documents

This directory contains simplified explanations of the Binance Market Making project for different audiences.

## Files

- **BINANCE_PROJECT_EXPLAINED.md** - Comprehensive explanation of the dataset, project goals, and why this consultancy project is useful. Written in plain language for anyone to understand.
- **STATISTICAL_METHODS_ALIGNMENT.md** - Detailed mapping of statistical methods (MLR, SLR, GLM, time series, t-tests, ANOVA, etc.) to project applications.
- **SUMMARY_QUICK_REFERENCE.md** - Condensed quick reference guide to key project elements.

## Purpose

These documents help explain:
- What the dataset contains and why it's valuable
- Who benefits from this project and how
- The key research questions being investigated
- Why testing market making models against real data matters
- How statistical methods align with project goals
- The technical approach used in simple terms

These explanations are particularly useful for:
- Non-technical stakeholders
- Students learning about market microstructure
- Practitioners considering market making strategies
- Anyone wanting to understand the practical applications of this research
