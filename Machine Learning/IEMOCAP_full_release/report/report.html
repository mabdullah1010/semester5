Summary

We ask how much UAR (unweighted average recall) is lost when an interpretable model replaces a black box for 4-class emotion recognition (neutral, happy+excited, sad, angry) on IEMOCAP, using leave-one-session-out evaluation on 3,958 utterances after removing partner-overlap. With named eGeMAPS features the best black box reaches UAR 0.564 and the best budgeted interpretable model 0.500 (gap +0.064 [+0.049, +0.079]). With WavLM features the black box reaches 0.679, but a model restricted to a readable number of features does not benefit (gap +0.207 [+0.189, +0.224]). A dense linear model on WavLM (no budget) gets 0.668, so the cost is set mostly by the complexity budget, not by linearity. Training on rater-vote distributions (soft labels) does not shrink the gap consistently.

1. Question and hypotheses

Question. How much accuracy do we lose by using an interpretable model instead of a black box for speech emotion recognition on IEMOCAP, and does that gap shrink when models are trained on the raters’ disagreement (soft labels) instead of a single majority label?

  • H1 Black-box models beat interpretable models on the same features.
  • H2 Most of the total gap comes from the features, not the model.
  • H3 The gap shrinks when training on soft labels.
  • H4 The gap differs on high-agreement utterances compared with all utterances.
  • H5 Overlapping speech hurts accuracy.

Any outcome is reportable; nothing was tuned to make a hypothesis work.

2. Data audit

Inventory. 151 dialogs and 10,039 utterance wavs were found, all 16 kHz mono 16-bit (dialog wavs: 16 kHz stereo). There are 0 unreadable files and 0 exact duplicates; 84,039 junk files (._*, .pk, .DS_Store) were skipped.

Labels. The official label is reproduced exactly by rule A (plurality of the three external raters, each rater counting once per listed category, ties to xxx): match rate 1.000 (rule B 0.997, rule C including self-evaluation 0.946). All 10,039 utterances, per-session counts and the 4-class set of 5,531 utterances match the dataset guide.

Rater agreement. Krippendorff’s alpha (nominal; multi-category votes kept as distributions) is 0.372 on all utterances and 0.504 on the primary set. By class (one-vs-rest, primary set): neu 0.412, hap 0.735, sad 0.634, ang 0.639. Neutral is the contested class. The actor’s own label includes the observers’ label in 69% of 1,575 self-evaluated utterances.

Approximate human ceiling. Predicting each rater’s vote from the other two raters (only where those two agree) gives UAR 0.657 and WA 0.687. This is called approximate because it is optimistic in one way (items without agreement are skipped) and not like-for-like in another (a single rater is compared with a consensus); it is not a true upper bound, and 2 of our models exceed it (l2lr+wavlm, mlp+wavlm).

Overlap. Partner speech overlaps 88% of 4-class utterances in the transcript timings (padding 0.1 s), more for angry (97%) and neutral (94%) than sad (68%); class and overlap are strongly dependent (chi-square p = 2e-116). Every utterance wav is a sample-exact copy of one channel (the speaker’s own microphone) of the stereo dialog, so the partner is present only as microphone bleed. A stereo crosstalk detector was calibrated on the transcript overlaps but failed its own gate (recall 0.206 at tau = 5 dB, required 0.5), so it was dropped. The strictly clean policy P1 keeps only 668 utterances (37 angry) and fails the retention rule. The primary policy is P2: overlapping spans are cut and the longest clean piece (>= 1 s) kept, giving 3,958 utterances (neu 1163, hap 1062, sad 962, ang 771); every class keeps 65% or more of its P0 count. P0 (all clips) is carried through as a secondary run.

Leakage checks. Leave-one-session-out means no speaker appears in both train and test (asserted in tests and in M3). A shuffled-label logistic regression gives UAR 0.248, 0.243, 0.251 (must lie in 0.22-0.28), a majority predictor gives exactly 0.25 in every fold, and per-speaker z-scoring cuts a speaker-ID probe from 0.823 to 0.059 (chance 0.100). Re-extracting 20 random clips reproduced features exactly (max abs difference 0 for eGeMAPS and 0 for WavLM). 299 near-duplicate candidates were checked by waveform correlation (max 0.19): none are duplicates. Scripted lines are reused across sessions, but scripted-dialog UAR is lower than improvised for every model, so text memorization is not inflating scores.

3. Method

Features. Interpretable: the 88 eGeMAPSv02 functionals (openSMILE, named acoustic measurements). Learned: mean-pooled hidden states of frozen microsoft/wavlm-base-plus (13 layers); one layer per fold is chosen with a logistic-regression probe on an inner validation session (training sessions only). Layers chosen: fold 1: 10, fold 2: 10, fold 3: 9, fold 4: 11, fold 5: 9.

Evaluation. Five folds, each testing on one session and training on the other four; hyperparameters are tuned on a held-out training session and the model is refit on all four training sessions. Preprocessing (median imputation, per-speaker z-scoring using each speaker’s own unlabeled features, global scaler) is fit inside each fold only. Metric: UAR; secondary: accuracy and macro-F1. Significance: paired bootstrap over test utterances resampled within each session (2,000 resamples, 95% intervals); McNemar’s test as a second opinion. Stochastic models use 3 seeds.

Complexity budget (fixed before any M7 result). Interpretable = L1 logistic regression with at most 20 nonzero features (a feature counts if any class uses it) or a decision tree with at most 16 leaves. Black boxes: HistGradientBoosting, random forest, MLP. An unbudgeted L2 logistic regression is reported as a reference. The best model per cell is chosen by mean inner-validation UAR, never by test UAR.

Soft labels. Each training utterance is expanded into one row per class with nonzero rater-vote mass; the row weight is that mass times the balanced class weight of the utterance’s hard label (the weights of one utterance sum to its class weight). The MLP minimizes weighted cross-entropy against the soft target. Tuning and test labels stay hard, so hard- and soft-trained models are scored on identical test sets.

4.2 Price of interpretability

Sweeping the L1 penalty on eGeMAPS, UAR rises with the number of features and flattens at about 0.562; it is within 3 UAR points of the best eGeMAPS black box (0.564) from about 21 features and within 1 point first at about 65 features. No eGeMAPS model gets near the WavLM black box (0.679). Decision trees do not follow this pattern: UAR peaks at 4 leaves (0.503) and then declines (overfitting at minimum leaf size 5), so trees never come within 3 points of the black box.

Sensitivity of the headline. The tuned L1 model used only 11.4 features on average, under-using the budget. A fixed penalty chosen from feature counts only (largest C with at most 20 features in every fold, 14-17 features) gives UAR 0.525 and Delta_model(eGeMAPS) = +0.039 [+0.025, +0.054] instead of +0.064 [+0.049, +0.079]. H1 still holds on eGeMAPS; the pre-registered number remains the headline.

5. What the interpretable model learned

The budgeted L1-LR chose 24 different eGeMAPS features across the five folds; only 4 were chosen in every fold (mean fold-to-fold Jaccard 0.43), so the specific list is unstable when features are correlated. The stable part is a loudness story: for angry, steeper loudness rises and falls and higher voiced spectral flux; for sad, lower overall sound level, more variable unvoiced-segment length and a lower low-frequency spectral slope. In folds 1, 2, 4 the model has no coefficients at all for neutral and happy: it separates sad and angry from the rest and decides between neutral and happy through its intercepts, which helps explain its UAR of 0.500. Trees built in different folds also use different features (mean Jaccard 0.16). These are associations in acted speech, not causal statements. 6. Limitations

  • Acted emotion from 10 actors in 5 sessions; five folds and one dataset, so differences between sessions (fold 4 is the hardest in most runs) matter and generalization to natural speech is untested.
  • The approximate human ceiling is optimistic in how it filters items and is not like-for-like with consensus-label evaluation; it should not be read as an upper bound.
  • Overlap handling: utterance wavs are single-microphone, so partner bleed rather than partner speech is what contaminates a clip. The crosstalk detector failed its recall gate (0.206 < 0.5). The primary policy P2 cuts whole overlapped spans, which also removes the speaker’s own speech during them, drops 28% of clips non-randomly, and shifts the class mix slightly; P0 is reported alongside.
  • Happy and excited are merged; frustration and other classes are excluded, which removes the hardest, noisiest categories. Soft labels are 4-class renormalizations (38.9% of primary-policy utterances had votes outside the 4 classes).
  • The ‘best’ budgeted model is chosen by inner-validation UAR; this is leak-free but noisy (the budgeted L1-LR on WavLM is unstable; validation chose tree while l1lr scored higher on test), and the tuned L1-LR under-used its budget, so Delta_model(eGeMAPS) is +0.039 with a fixed-penalty sensitivity point versus +0.064 pre-registered.
  • About 20 H3/H4-related intervals are reported at 95% without multiple-comparison correction; bounds close to zero (for example H3 on eGeMAPS) are fragile.
  • Gradient boosting’s built-in early-stopping split can place duplicated soft-label rows of one utterance on both sides. The L1 sweep on WavLM (M8.3), a cleaned-training variant (M9.5), a 5-class variant (M10.5) and permutation importance for the black box (M11.3) were not run.
  • Text was not used; a text or multimodal comparison is out of scope.

7. Conclusion

On IEMOCAP, with leave-one-session-out evaluation, black-box models beat interpretable ones by +0.06 [+0.05, +0.08] UAR on named acoustic features and by far more on learned features. The cost is not a fixed number: it depends on the complexity budget (a dense linear model on WavLM is within 0.010 UAR of the MLP, but a 20-feature one is not), and it is not explained by label noise or by soft labels. In practice: an L1 model on eGeMAPS comes within 3 UAR points of the best eGeMAPS black box at about 21 features, although the tuned model constrained to at most 20 features was 0.064 behind; if accuracy matters most, the learned representation with a dense model is clearly better.
